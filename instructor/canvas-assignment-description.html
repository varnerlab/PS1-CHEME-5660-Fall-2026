Get started

Read the PS1 instructions and grading rubric. Download Source code (zip) under Assets on the PS1 release page.

Extract the ZIP. In VS Code, choose File → Open Folder and select the extracted PS1 folder containing README.md, Project.toml, and check_submission.jl. This assignment is supported with Julia 1.12.7 and uses VLQuantitativeFinancePackage, as in the lecture examples.

In VS Code, choose Terminal → New Terminal. From the extracted PS1 folder containing Project.toml, run this setup command once: 

julia --project=. --startup-file=no -e 'using Pkg; Pkg.instantiate()'

The first setup needs an internet connection and may take several minutes.

Complete your work

Choose Standard or Advanced and enter standard or advanced as the only text in TRACK.txt. Save the file. The starter selects standard. Standard uses the lecture package to build and price a bill and a note, then reprice the note after a yield change. The checker supplies the duration and convexity report. Advanced includes the same valuation tasks, then compares four Treasury strategies for a firm with USD 74,000 today and a USD 100,000 payment due in seven years. The firm cannot borrow or add money. Students use the supplied comparison function and recommend one of the four strategies, using funding counts and shortfall amounts to explain the risk of missing the payment.

  • Standard: complete src/Standard.jl and answer the three discussion questions in responses/Standard.md.
  • Advanced: complete the three valuation tasks and the funding-comparison call in src/Advanced.jl, then answer the three discussion questions in responses/Advanced.md. All Advanced work is contained in these two files.

Save your code and run the checker to display the financial results in the terminal. Open your selected responses/Standard.md or responses/Advanced.md file in VS Code and edit the Markdown source. Replace each TODO: Write your response here. line with your answer, keeping the answer markers. Save your answers and rerun the checker before creating the ZIP.

Only your selected track is graded. An accepted 4 on Advanced earns one Magic Point, including through an eligible revision. This bonus is awarded once for PS1. Keep the function docstrings and answer markers. Leave the supplied support code, data, tests, reports, and checker unchanged.

Changing tracks: You may switch between Standard and Advanced before submitting or on an eligible revision. Each submission is graded only on the track selected in TRACK.txt. If you change tracks, update TRACK.txt, complete that track's code and response files, and rerun the checker. You may reuse your own valuation code, but the discussion questions differ between tracks. We keep your highest score across all submissions, even if you change tracks. An unfinished Advanced submission is graded under the Advanced rubric; it does not automatically receive a Standard grade.

Check and submit

In VS Code, choose Terminal → New Terminal. Run this command from the extracted PS1 folder containing Project.toml and check_submission.jl: 

julia --project=. --startup-file=no check_submission.jl

The checker runs the tests, displays your results, and creates MANIFEST.txt. Tests are expected to fail until you complete the starter code. Advanced also saves the comparison in results/advanced-strategies.csv and individual futures in results/advanced-scenario-outcomes.csv. Passing all tests gives pending completion review. To earn a 4, the teaching team must also accept your code, documentation, and discussion answers.

  1. Run the checker, then ZIP the entire extracted PS1 folder, including TRACK.txt, src, responses, data, and MANIFEST.txt. If you cannot run the checker, submit your attempted work without MANIFEST.txt.
  2. Name the ZIP CHEME-5660-PS1-<your netid>.zip, replacing <your netid> with your NetID. For example, CHEME-5660-PS1-abc123.zip.
  3. Upload the ZIP to this Canvas assignment by the initial deadline. The checker does not upload it for you.
